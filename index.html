1. Etiquetas de Estructura

<!DOCTYPE html>: indica al navegador que el documento usa HTML5.
<html lang="es">: etiqueta raíz. Atributo lang define el idioma (accesibilidad y SEO).
<head>: contiene metadatos (no visibles): título, enlaces a CSS, meta etiquetas.
<meta charset="UTF-8">: define la codificación de caracteres (tildes, ñ, etc.).
<meta name="viewport">: hace la página responsiva en móviles.
<body>: contiene todo el contenido visible de la página.
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Mi página</title>
  </head>
  <body>...</body>
</html>
