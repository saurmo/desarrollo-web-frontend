Display: grid

Grid organiza elementos en dos dimensiones: filas y columnas a la vez. Mientras Flexbox reparte elementos en una línea, Grid define primero una cuadrícula y luego coloca los elementos dentro de ella.

1. Activar Grid

Con display: grid y grid-template-columns defines la cuadrícula.

display: grid; grid-template-columns: 1fr 1fr 1fr;

¿Flex o Grid?

FlexboxGrid
Una dimensión (fila o columna) Dos dimensiones (filas y columnas)
El contenido manda: los ítems definen el tamaño El layout manda: la cuadrícula define el tamaño
Navbars, botones, alinear elementos Estructura de página, galerías, dashboards

No compiten: lo normal es usar Grid para la estructura general y Flexbox para el interior de cada bloque.
