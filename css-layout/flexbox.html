Display: flex

Flexbox organiza elementos en una sola dimensión: una fila o una columna. Al escribir display: flex en un elemento, ese elemento se vuelve contenedor flex y sus hijos directos se convierten en ítems flex.

1. Activar Flexbox

Sin display: flex los divs se apilan. Con él, se colocan en fila.

display: flex; gap: 12px;
